# git-cli 

One command to synchronize on Git.



## OS

| windows 10/11 |      | ✅    |
| ------------- | ---- | ---- |
| mac           |      |      |
| android       |      |      |
|               |      |      |

## Usage

Add the Environment Variable for local user, Select Path then use path of git-cli.exe

```
git-cli -u {remote_url} 

or

git-cli -u {remote_url} -m "first commit"
```
