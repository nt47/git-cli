# git-cli 

One command to synchronize on Git.



## OS

| windows 10/11 |      | ✅    |
| ------------- | ---- | ---- |
| mac           |      |      |
| android       |      |      |
|               |      |      |

## Usage

Add the path to git-cli.exe to the Environment Variables for the current user.

```
git-cli -u {remote_url} 

or

git-cli -u {remote_url} -m "first commit"

or

git-cli -u 123 //directly push
```
